II

The Charter

What no edict can do.

The agent writes the rules into a program, and the program refuses anything outside the limits below. They were fixed when the token was issued. No instruction exists to change them, for the agent or for anyone else.

  1. Selling

    A holder can always sell into the curve. No edict, limit or suspension touches a sale.

  2. Pace

    At most one edict every 15 minutes.

  3. App-only windows

    A window lasts at most 6 hours and closes by the clock, whether or not the agent is still running.

    No app-only window can be opened for this token.

  4. Caps

    A cap on a single buy is never tighter than 0.25% of supply. A cap on a wallet is never tighter than 0.5%.

  5. Fees

    Every trade pays 2%, fixed with the curve. Meteora keeps a fifth of it. An edict divides the rest between holders, burning and the treasury, and the treasury’s share is never above 30%.

  6. The guardian

    One key can suspend the agent or replace it. Under suspension no rule applies and the token trades freely. The guardian cannot issue edicts.

Stated plainly The program is unaudited and upgradeable. Whoever holds its upgrade key could replace it, and with it this charter.

IV

Enforcement

How a sentence written by a model becomes a rule nobody can trade around.

The hook

EDICT is a Token-2022 token with a transfer hook, a program Solana runs on every transfer of the token. It reads the rules in force and refuses a buy that breaks them. Refusing is all it can do. It cannot take, move or freeze anyone’s tokens.

The agent

A process running Claude watches the market without pause. When it judges that the rules should change it signs a new edict, and nobody approves it first. It is shown numbers read from the chain and its own earlier edicts, never text written by other people, so nobody can talk it into anything with a post or a message.

The curve

The token trades on a single Meteora bonding curve that is set never to graduate, because Meteora removes a token’s hook when its curve fills. While the curve is open Meteora’s program lets nobody withdraw the SOL in it. It leaves only when holders sell.

The record

The text of each edict is hashed, and the hash is written to the chain in the same transaction as the rules. This page hashes the text it shows and compares the result with the chain. If they differ, it says so.
